# Azorte Fashion Web

> A front-end demo of an online fashion store, built with HTML, CSS and JavaScript.

Made as part of an **AI and ML Workshop**, with the help of **Codex** (an AI coding assistant).

## 📖 About

Azorte Fashion Web is a visual representation of an online fashion store. It shows how a shopping website can look and feel, with different categories and options for a customer to explore.

The project was built entirely through prompting Codex, to practise and show **prompt-writing skills**: describing what I want clearly, then refining the result step by step.

## ✨ Features

- Browse fashion items by different categories
- Multiple options for customers to choose from
- Simple, clean front-end design
- Runs fully in the browser, with **no database or backend required**

## 🛠️ Tech Used

| Type | Details |
|------|---------|
| Languages | HTML, CSS, JavaScript |

## ▶️ How to Run

No installation needed.

```bash
git clone https://github.com/<your-username>/Azorte-fashion-web.git
cd Azorte-fashion-web
```

Then open `index.html` in any web browser (double-click the file).
